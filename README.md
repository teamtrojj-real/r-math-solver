# R Math Solver

Сайт для решения математических задач на языке R (Shiny + shinylive).

**Сайт:** https://teamtrojj-real.github.io/r-math-solver/

## Блоки (по 10 задач)

- **Финансовая математика** — простые и сложные проценты, непрерывное начисление, дисконтирование, эффективная ставка, аннуитетный кредит, накопления, NPV, IRR, срок роста капитала.
- **Нахождение производной** — степенная функция, многочлен, произведение, частное, сложная функция, экспонента, логарифм, вторая производная, касательная, экстремумы на отрезке (функция `D()`).
- **Статистика** — описательные статистики, дисперсия, квартили и выбросы, гистограмма, доверительный интервал, t-тесты, корреляция, регрессия, нормальное распределение.

На главной странице — кот-маскот Финик.

## Запуск в RStudio

```r
install.packages(c("shiny", "bslib"))
shiny::runApp()
```

## Публикация

При каждом push в `main` GitHub Actions экспортирует приложение через `shinylive::export()` и выкладывает его на GitHub Pages — R работает прямо в браузере (webR), сервер не нужен.
